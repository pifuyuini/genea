# Demo2 文学人物头像

公开包包含全部 46 张独立的 256×256 JPG 头像、[人物绑定清单](manifest.json)和三份原始生成提示词：[图一](prompt-01.txt)、[图二](prompt-02.txt)、[图三](prompt-03.txt)。头像是原创文学写实插画，不复刻演员，也不代表原著指定容貌或统一时间点。

绑定清单以固定 `person_id` 对应照片文件名，图号、行、列从 1 开始，按从上到下、每行从左到右排列。三个生成批次分别为 16、16、14 人；末批的两个空格不对应人物。未详名编号用于区分节点，不表示出生排行。

公开发行不包含原始生成矩阵或裁切脚本。应用直接使用 `demo2/data/photos/` 中的独立头像；不需要原矩阵、图像库或 macOS 裁图工具。照片与人物资料绑定固定，重新构建文学数据不会改变头像。

在源码目录执行以下命令可检查快照和公开头像的数量、绑定及 JPEG 尺寸：

```sh
python3 -B demo2/build_demo.py --check
python3 -B -m unittest discover -s tests -p 'test_demo2_portraits.py'
```

新启动的本地 Demo2 工作副本携带这些头像。明确复用已有副本时，启动器保留原数据和已编辑内容，不会重新填入照片。
