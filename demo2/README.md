# Demo2：《百年孤独》布恩迪亚家族

这是 Genea 的第二份公开文学演示数据，包含完整七代主线的剧情信息和结局关系。它与《红楼梦》Demo1、真实 `data/` 各自独立；46 人配有原创文学写实插画头像，人物资料与照片均绑定到固定 ID。

七行分别为第一代至第七代，共 **46 人、53 条边：49 条亲生关系和 4 条养亲关系**。第三行左侧保留阿尔卡蒂奥、奥雷里亚诺·何塞、桑塔索菲亚、费尔南多与蕾娜塔五人，随后把上校的十七个儿子列在右侧。人物简介保留西语姓名和简短角色，用来区别反复出现的何塞、奥雷里亚诺、蕾梅黛丝和阿玛兰妲。

主线从何塞·阿尔卡蒂奥·布恩迪亚与乌尔苏拉共同建立的家庭，经过上校及其十七个儿子、阿尔卡蒂奥与桑塔索菲亚的三个孩子、第四代双胞胎、梅梅与毛里西奥，到第六代奥雷里亚诺·巴比伦，以及他与姨母阿玛兰妲·乌尔苏拉生下的末代孩子。这里的“第几代”同时是演示的七行布局；亲子方向以实际登记的父母和孩子为准。

## 运行与复用

在项目根目录使用已有 Python 环境运行：

```sh
python3 -B demo2/run_demo.py
```

默认地址是 `http://127.0.0.1:8767`，首次默认启用实验功能，复用副本时尊重已保存的开关选择。旧 `--experimental-cross-generation` 参数仅提供首次默认值。每次默认启动都会创建一个新的 `tmp/<时间戳>-genea-demo2/`，立即写入 `.codex-tmp` 标记，再把这份公开数据复制到其 `data/` 子目录。终端会显示实际副本路径。编辑只保存到该副本；退出不会删除它，也不会重置旧会话。

若要继续某个已有独立副本中的修改，明确传入上次终端显示的 `data` 目录：

```sh
python3 -B demo2/run_demo.py --port 8767 \
  --data-dir tmp/20261004-120000-000000-genea-demo2/data
```

上面的时间戳只是路径格式示例，请替换为实际路径。复用目录必须已存在且包含 `workspace.json`，启动器不会创建空白会话或覆盖其中的编辑。真实项目 `data/`、Demo1 的 `demo/data/` 和 Demo2 的 `demo2/data/`，以及这些目录的子目录都不能作为复用目标。不要使用 `demo2/.runtime`；无需增加新的忽略规则。

## 实验开关与人物头像

顶部开关按每份工作副本单独记忆。Demo 2 首次开启，可直接编辑跨代亲子关系；关闭后，跨代关系和历史仍完整保留，工作区暂为只读，重新开启恢复编辑。检查家谱和高级关系查询也随总开关显示。

全部 46 人已接入原创文学写实插画头像。头像按 16＋16＋14 人的固定位置清单裁成 256×256 JPG，新启动副本会一并复制照片。公开包保留独立头像、提示词和绑定清单，不含原始生成矩阵。详见 [头像与绑定说明](portraits/README.md)。简介、人物 ID、关系与时间戳保持不变；已有试用副本中的编辑不会被更新覆盖。

## 数据边界

- 上校共有 **18 个亲生儿子**：与庇拉尔生下奥雷里亚诺·何塞，加上十七名各有不同母亲的奥雷里亚诺。五位详名是 Triste、Centeno、Serrador、Arcaya、Amador。其余十二人的完整姓名未逐一列出，以“未详名01–12”区分节点，编号不表示出生排行。没有把这些不同母亲捏合成一个共享的“未知母亲”。
- 丽贝卡的亲生父母是尼卡诺尔·乌略亚与丽贝卡·蒙铁尔，养父母是创始夫妇，两组身份分别登记。
- 奥雷里亚诺·何塞先被蕾梅黛丝·莫斯科特认作长子，后由阿玛兰妲收养。这两项明确的养亲关系各有独立特殊边；普通照顾、陪伴不一律转换成收养。
- 阿玛兰妲·乌尔苏拉位于第五行，她到第七行末代孩子的母子边必须跨行；第六行奥雷里亚诺·巴比伦到第七行孩子的父子边仍相邻。跨行模式保留这两位实际父母，不把母亲移动到第六行。
- 无子婚姻——何塞·阿尔卡蒂奥与丽贝卡、上校与蕾梅黛丝、加斯通与阿玛兰妲·乌尔苏拉——只写在简介中。佩特拉与双胞胎的伴侣往来也只保留简介，没有夫妻边或虚构的亲子边。佩特拉与加斯通因此可为孤立人物。
- 创始夫妇为表亲这一背景只写简介，不为补出亲缘计算结果而虚构他们未列出的祖先。不增加胎儿、未具名旁支或全小说的其他交往人物网络。

## 演示路线

1. 选择奥雷里亚诺上校与创始人，检查普通父子链；比较各代同名人物的西语姓名、短角色和独立 ID。
2. 选择阿尔卡蒂奥与奥雷里亚诺·何塞：两人共享母亲庇拉尔，两位父亲又是兄弟，所以可同时出现“兄弟”和“堂兄弟”的不同依据。引擎不额外区分全同胞与半同胞。
3. 选择丽贝卡与尼卡诺尔、丽贝卡·蒙铁尔，再与创始夫妇比较，观察亲生父母和养父母分别登记。
4. 从奥雷里亚诺·何塞看阿玛兰妲：原登记链是“养母”，直接血亲称谓是“姑母”，两套依据分别保留。精确血亲已有结果时，不要求日常称呼层再重复附加“养母”。
5. 查看第三行右侧十七子：每人都有独立 ID 和上校父子边，十二个编号只做同名消歧。
6. 选择末代孩子与母亲阿玛兰妲·乌尔苏拉，确认母子关系越过第六行；再查看其父亲奥雷里亚诺·巴比伦。
7. 选择佩特拉或加斯通与其他人物，观察未登记连接的提示；自查仍返回“自己”。

## 重建与验证

快照通过核心 API 创建，固定 ID 与时间 `2026-10-04T00:00:00+00:00`，重建结果可直接审阅差异：

```sh
python3 -B demo2/build_demo.py
python3 -B demo2/build_demo.py --check
```

数据与启动器测试位于 `tests/test_demo2_data.py`，头像绑定与尺寸验证位于 `tests/test_demo2_portraits.py`。它覆盖快照重现、人数与边数、十七子、亲生及养亲边界、跨行母子关系、典型多重亲缘，以及全部 **46² = 2,116** 个有向人物对（含自己与孤立人物）。反转边录入顺序时推导层结论保持稳定；原逐级链仍遵守原有 BFS 的顺序规则。
